Safety & Setup

The shared PIN is a demo gate, not secure authentication. Do not use it to protect private information.
  • Use Supabase Auth accounts for real student-only access.
  • Keep Row Level Security enabled on every exposed table.
  • Never put a Supabase secret or service-role key in this file.
  • Don't post your full name, password, address, or private details in chat.
  • The web viewer only supports sites that permit embedding.

Version 1 prototype. Supabase live chat activates only after a secure authentication flow and database policies are configured.
